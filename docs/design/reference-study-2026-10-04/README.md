## Component and identity contract

- Home: settled layout gives balance first, then four equal icon actions, investments and owned tokens. Cents use smaller quieter type. Existing Senryo mode truth remains adjacent. No invented chart belongs under a total without portfolio-history data.
- Card: card face is a primary object. Eye/freeze/limit controls are compact functional icons. Amount pair and actual recent activity follow it. “To repay”, backing yield and weekly bars need their own data/business rules and are not inherited.
- Markets/social: preserve real asset marks, chain/venue/status badges, trader avatars, buy/sell labels and chart identities. R11 has useful optical sizing and aligned numeric columns; unknown issuer logos need labelled fallback, not unrelated art.
- Review: source avatar/account → actual asset/network mark → recipient, exact amount/fee/total and a genuine finality result. SUI/Google/Slush marks are reference identities, not Senryo assets.
- Material: source light/dark hierarchy is observable; exact blur algorithm, typography font, renderer and shadows are unknown. Use existing target tokens and original assets; no competitor raster crops in the app.
