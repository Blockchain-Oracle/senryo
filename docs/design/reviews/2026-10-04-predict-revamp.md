# Predict: mobile hierarchy correction

The user's latest correction takes priority: native Senryo is a Monad pair-trading app with predictions, money flows, cards and social discovery. Predict must put markets ahead of controls. This supersedes the stacked-filter layout in the first prediction discovery build; it does not remove any prediction model or execution work from the register.

## Reference lock before implementation

The supplied Phantom recording (R2, FT050–054) remains the primary prediction journey reference. Refero's [Phantom selector](https://refero.design/screens/1088fef2-8852-4852-91ac-5bf20af52786) was visually inspected: secondary time options open on demand instead of occupying permanent rows. Refero's [UGLYCASH discovery](https://refero.design/screens/ed101814-46f4-4a36-8327-9487e097aa6b) and [market detail](https://refero.design/screens/494ee0f2-6ac3-4fa8-ae78-47cfa9958e1f) were visually inspected: a readable question, real identity and clear outcome values lead; contract details follow. Their political/sports markets, prices, fees and trading capabilities are not Senryo product authority.

Preserve Senryo's Living Lacquer tokens, native symbols, authored entity marks, Fomo Markets shell and Phantom action fan. Adapt the references' hierarchy and progressive disclosure, not their colours or advertised capabilities.

| Decision | Evidence and intent |
|---|---|
| One toolbar: market model and Filters | User rejected three stacked chip rows; Phantom's on-demand selector |
| Asset, Live/Recent and 5m/15m/price-event choices in a sheet | All options retained, with draft selection and explicit apply |
| Full-width market cards | User's readability objection + Refero discovery/detail; questions and outcomes must not compete in narrow columns |
| Visible save action | Existing watchlist contract, discoverable without guessing a long press |
| Default to price events | Broader readable questions; short Up/Down intervals remain available under Filters |
| Provider/network/execution truth remains visible | Public Polymarket shares settle on Polygon; Castora contests on Monad; both currently view-only |
| Source timestamps and bounded coverage below results | Preserve freshness evidence without repeating provider implementation metadata above discovery |

## Acceptance

Accepted on the existing iOS 26.5 simulator in Practice on 5 October:

- Actual binary questions, indicative outcome values and view-only state render in full-width cards. [List capture](assets/2026-10-05-predict/list.png).
- Bitcoin + 15-minute draft selection followed by Cancel preserves the original All assets + Price events list.
- Show markets applies Bitcoin + 15-minute choices; the list shows real live/upcoming questions.
- Saved state changes in the card and detail header; removing it restores the original watchlist state.
- Detail opens with outcomes and a real history chart. Down selects the correct history; tapping a sample updates its price/time. Resolution rules and Market details expand separately; Back preserves list filters. [Detail capture](assets/2026-10-05-predict/detail.png).
- Castora model switch shows actual resolved Monad contests with a closed-entry notice and numerical settlement facts. Returning to binary markets preserves Bitcoin + 15-minute filters. [Contest capture](assets/2026-10-05-predict/contests.png).
- Recent results + Ethereum + 5-minute choices show resolved events. Reset restores Live & upcoming + All assets + Price events in the draft; Show markets applies that reset. [Filter capture](assets/2026-10-05-predict/filters.png).
- The overnight offline state preserved last-known data and marked the refresh failure. Expired cached markets offer Refresh. Reload restored connectivity and real provider observations; no fabricated fallback values.

Mobile typecheck, scoped Biome and all 31 repository invariant rules pass. All 17 workspace typecheck tasks passed; the separate indexer gate passed after regenerating its stale local types. iOS and Android Hermes exports pass (final post-copy export recorded with the release).
