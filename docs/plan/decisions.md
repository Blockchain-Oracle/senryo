Value = liquid + reserved; a virtual share offset and the house seed minted as the first shares stop donation and first-depositor tricks; unpaid redemptions roll to the next hour. Earn shows value, reserved vs liquid, each hour's result and risk in words, never an APY. No reference product had epochs; this is new design.
