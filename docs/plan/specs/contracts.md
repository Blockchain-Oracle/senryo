# Spec: contracts (SenryoCore and friends)

Source of truth for S2. Plan: `00-plan.md` §2.1, decisions D-005/006/009/010/032/036/039. Risk maths: `risk-math.md`.
Toolchain: forge 1.8.x, solc 0.8.31, osaka, `network = "monad"`, OZ 5.7.0. All numeric parameters live in `src/libraries/Constants.sol` or `script/SeedConstants.sol` (invariant `sol-no-magic-numbers`).

## Units
`usd6` (1e6 = $1, AUSD/USDC native decimals) · `PRICE` 1e18 USD per unit · `SIZE` 1e18 units of underlying · `BPS` 1e4 · `RATE` 1e18 per second. Chainlink 8/18-decimals normalised to 1e18 in `SessionOracle`. Rounding **always against the account** (OZ `Math.mulDiv` with explicit `Rounding`): collateral, profits, share mints round down; losses, fees, margin round up.

## Module responsibilities (every event carries `address indexed user` where a user exists)
- **AccountLedger** — `Account{uint128 usdc; uint128 ausd; uint128 holds; uint128 cardDebt; uint128 envelope; uint64 nonce; uint32 positionBitmap}` packed into one storage page. `deposit(token, amount)`, `depositFor(token, amount, beneficiary)` (credits measured balance delta, never reverts on amount), `withdraw(token, amount, to)` (to == msg.sender allowed in session; other `to` is a step-up flow client-side). `ReentrancyGuardTransient`. `nonce++` per mutation. Events `Deposited(user, payer, token, amount, source{DIRECT,AURORA,INBOX,VOUCHER}, nonce)`, `Withdrawn(user, to, token, amount, nonce)`, **`AccountRiskUpdated(user, nonce, equityInit, imTotal, mmTotal, holds, cardDebt, envelope, freeToTrade, freeToSpend)` at the end of every mutation**.
- **CollateralConfig** — per token `{enabled, haircutBps, usdFeed, depegFloor}`; AUSD `0x0000…9012a` and USDC `0x7547…b603` (verify USDC decimals onchain at deploy).
- **MarketRegistry** — `Market{feed, calendarId, imBps, mmBps, feeBps, baseSpreadBps, devSpreadBps, oiCapAbs, oiCapPoolBps, skewCapPoolBps, tradeCapPoolBps, maxProfitBps, fundingFactor, borrowBase, borrowSlope, clampBps, reopenClampBps, status}`; `lowerX` (GUARDIAN, instant) vs `setX` (PARAM_ADMIN, timelocked).
- **MarketAccounting** — per market `longSize, shortSize, longEntry18, shortEntry18 (Σ size×entry, usd18), reservedProfit, fundingIndex (int), borrowIndex, lastAccrual`; lazy `_accrue(marketId)`; `MarketStateUpdated`.
- **PerpModule** — one net position per (user, market): `Position{uint128 size; uint128 entry; int128 fundingSnap; uint128 borrowSnap; uint64 openedBlock; bool isLong}`. `increase(marketId, isLong, notionalUsd6, acceptablePrice, deadline)`, `decrease(...)`, `close(...)`, view `quote(...)`. Deadlines are timestamps. `MIN_HOLD_BLOCKS` before a profitable close (anti-flash). Single event `PositionUpdated(user, marketId, kind{OPEN,INCREASE,DECREASE,CLOSE,LIQUIDATE,TRIGGER}, isLong, sizeDelta, execPrice, oraclePrice, fee, realizedPnl, funding, borrow, sizeAfter, entryAfter, nonce)`.
- **TriggerOrders** — user-signed EIP-712 TP/SL (price, reduce size, expiry); `executeTrigger(orderId)` permissionless when the oracle crosses; `TriggerPlaced/Cancelled/Executed`. No resting limit orders.
- **CardModule** — `setSpendAllowance(dailyLimit, expiry, sig)` (user EIP-712, D-032) · `setCardEnvelope(amount)` · operator `placeHold/increaseHold/captureHold/releaseHold` **only within the live allowance** · `refund(user, refId, amount)` · `repayCardDebt(amount)` · release by anyone after `expiry + HOLD_RELEASE_GRACE`. Release-only mode flag per hold source (mainnet Lithic sandbox, D-036). Capture ≤ hold → release remainder; over-capture within `CAPTURE_OVER_TOLERANCE_BPS` → debit free collateral, remainder becomes `cardDebt`. `holdId = keccak256(issuer, issuerTxnToken)` (placing twice reverts → idempotent). Events `AllowanceSet`, `HoldPlaced(holdId, user, amount, expiry, fromEnvelope, nonce)`, `HoldIncreased`, `HoldCaptured(holdId, user, captured, released, debtCreated)`, `HoldReleased(holdId, user, amount, reason)`, `CardRefunded`, `CardDebtRepaid`, `CardEnvelopeSet`.
- **LiquidationModule** — `liquidate(user)` permissionless; requires every held market OPEN; waterfall in `risk-math.md`; `Liquidated`, `InsuranceCovered`.
- **SessionOracle** — `observe(marketId)` (state-changing, permissionless, keepers poke) and view `peek(marketId) → {price18, updatedAt, status, spreadBps}`. Every read: answer > 0; `updatedAt ≤ block.timestamp` (future-date guard → STALE); `answeredInRound ≥ roundId`; age ≤ heartbeat + `FEED_GRACE`; |Δ vs last accepted| ≤ `clampBps` (`reopenClampBps` after CLOSED) else CIRCUIT. CIRCUIT exits only by 3 rounds within `CONFIRM_BAND_BPS` spanning ≥ `CONFIRM_SECONDS`, or timelocked `acceptFeedPrice(market)` (accepts the feed's own answer; **never a price argument**). Feed `description()` hash asserted on set. `MarketStatusChanged`, `PriceRejected`.
- **MarketCalendar** — weekly 15-min slot bitmap (672 slots in 3 × uint256; slot 0 = Monday 00:00 UTC, `WEEK_ANCHOR = 345_600`); DST handled by conservative union (closed if closed in either EST or EDT). Gold: closed daily 21:00–23:00 UTC and Fri 21:00 → Sun 23:00 UTC. Holidays `(start, end)` windows: GUARDIAN adds instantly, removal timelocked. Cross-check slots with Chainlink market-hours before enabling (unverified).
- **LpVault** — `totalAssets()` = pool cash − trader net unrealised PnL + accrued fees receivable (mint uses the pool-favourable value, redeem the conservative one). `requestRedeem` → claim after `LP_REDEEM_DELAY`; `Deposit`, `RedeemRequested`, `Redeemed`.

## Invariants (Foundry stateful suites, `--network monad`)
I1 conservation: ERC-20 balance of core per token = Σ users + POOL + INSURANCE + CARD_FLOAT · I2 no double pledge: after any risk-increasing action `IM + max(envelope, holds) + BUFFER ≤ E_init` · I3 Σ open holds = Σ `Account.holds`; each hold captured at most once · I4 reserve: Σ maxProfit ≤ poolCash × `MAX_RESERVE_UTIL_BPS` · I5 only liquidation, capture and refund move value between two different accounts · I6 prices enter only via `SessionOracle.observe` · I7 holds never exceed the live spend allowance (D-032).
Handlers: deposit, withdraw, increase, decrease, trigger, placeHold, increaseHold, capture (under/over/expired), release, refund, repay, setEnvelope, setAllowance, liquidate, LP deposit/redeem, swapCollateral, oracle moves/circuit, time warps.
