```sh
claude mcp add --transport http monad-docs https://docs.monad.xyz/mcp
```

## 2. MCP servers / tutorials from Monad
- **Guide: build an MCP server for Monad Testnet.** https://docs.monad.xyz/guides/monad-mcp, repo `monad-developers/monad-mcp-tutorial`. It walks through a `get-mon-balance` tool with the MCP TS SDK and viem for Claude Desktop.
- `monad-developers/monad-mcp`: a Next.js/Vercel MCP server template (needs Redis). Generic scaffolding.
- `monad-developers/monad-sse-mcp`: SSE-based MCP tutorial.
- `monad-developers/AI-Werewolf`: an MCP game example.
- There is **no official "Monad MCP server" for on-chain actions** beyond these tutorials (as of this research). The docs MCP above is the official agent-facing endpoint.

## 3. Agent payments and identity (Track 04: Trust, Identity & AI Infra)
| Thing | Details |
|---|---|
| **x402 facilitator (Monad-run)** | `https://x402-facilitator.molandak.org`. Mainnet `eip155:143` (USDC `0x7547…b603`) and testnet `eip155:10143` (USDC `0x534b…43A3`). Pays gas and settles on-chain. Guide: /guides/x402. Use `@x402/evm >= 2.12.0` (2.22.0+ recommended) for the `upto` scheme. Repos: `monad-developers/x402`, `x402-rs`, `x402-workshop`. |
| **MPP (Machine Payments Protocol)** | `@monad-crypto/mpp` + `mppx` + `viem`. Server: `Mppx.create({ methods:[monad({account, recipient})] })` then `mppx.charge()` middleware, which returns HTTP 402. The client signs an ERC-3009 authorization ("pull mode"). Defaults to mainnet; pass `testnet: true` for testnet. Docs: /reference/mpp/overview |
| **ERC-8004 Trustless Agents** | Identity Registry `0x8004A169FB4a3325136EB29fA0ceB6D2e539a432`, Reputation Registry `0x8004BAa17C55a88189AE136b182e5fdA19dE9b63`, Validation Registry "coming soon". Guide: /guides/erc-8004 |
| **ERC-6551 token-bound accounts** | Guide: /guides/erc-6551 (canonical Tokenbound deployment) |
| **ERC-7730 clear signing** | Guide: /guides/clear-signing |
| **Mera (passkey keys)** | see mera.md |
| **P256 precompile `0x0100`** | on-chain passkey/WebAuthn signature verification for smart accounts |

## 5. Security and testing tools
- **Ultrafuzz** (`monad-developers/ultrafuzz`, active Sep 2026): an agentic orchestrator for smart-contract fuzzing and threat hunting. It runs specialized agents that generate fuzz tests and findings, then serves a dashboard and a report. **Run it only in disposable VMs**, because its agents use skip-permissions. Useful for a pre-submission security pass.
- Foundry ≥1.8 with `network = "monad"`: Monad gas, precompiles, and staking cheatcodes, plus trace decoding for Monad precompiles.
- Monad Solonet (`monad-crypto/monad-solonet`): a real local Monad network.
- `monad-crypto/paged-solady`: Solady adapted for MIP-8 paged storage.
- Tenderly and Phalcon for traces and simulation. Safe is supported. `monad-developers/soteria` validates Safe transaction JSON.
